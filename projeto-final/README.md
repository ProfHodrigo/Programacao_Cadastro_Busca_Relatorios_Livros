# Projeto Final — Biblioteca Virtual

## Objetivo

Construir uma aplicação web simples para cadastro e consulta de livros, utilizando Python, Flask e SQLite.

O projeto deve demonstrar os conteúdos trabalhados nas Aulas 1 a 8.

## Funcionalidades obrigatórias

1. Cadastrar livro.
2. Listar livros.
3. Visualizar detalhes.
4. Editar livro.
5. Excluir livro.
6. Buscar por título e/ou autor.
7. Filtrar por ano.
8. Filtrar por categoria.
9. Fazer upload opcional de PDF.
10. Permitir download do PDF.
11. Exibir página de relatórios em tabelas/quadros.

## Campos mínimos

- ID automático;
- título;
- autor;
- ano;
- categoria;
- editora;
- descrição;
- nome/caminho do PDF.

## Relatórios mínimos

- total de livros;
- total de autores distintos;
- ano mais antigo;
- ano mais recente;
- quantidade de livros por autor;
- quantidade por ano;
- quantidade por categoria.

## Requisitos técnicos

- Python 3;
- Flask;
- SQLite;
- HTML/Jinja2;
- Bootstrap pode ser usado via CDN;
- banco local;
- PDFs em pasta local do projeto;
- consultas SQL parametrizadas;
- arquivo `requirements.txt`;
- `README.md` explicando a execução.

## Fora do escopo obrigatório

Não é necessário implementar:

- login;
- permissões de usuário;
- API REST;
- React/Vue;
- Docker;
- gráficos;
- hospedagem em nuvem;
- leitura automática de conteúdo de PDFs.

## Apresentação

Na Aula 9, o grupo deverá demonstrar o sistema rodando e explicar as principais partes do código.
