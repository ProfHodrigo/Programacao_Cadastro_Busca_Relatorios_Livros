# Programação de Cadastro e Busca de Relatórios de Livros

Material didático para uma disciplina introdutória de programação web com foco na construção incremental de uma **Biblioteca Virtual**.

## Organização do semestre

| Aula | Data | Tema |
|---|---|---|
| 1 | 15/10/2026 | Apresentação da disciplina, preparação do ambiente e primeiro projeto |
| 2 | 22/10/2026 | Fundamentos de Python aplicados ao domínio de livros |
| 3 | 29/10/2026 | Flask, rotas, templates e formulários |
| 4 | 05/11/2026 | SQLite e início do CRUD: criar e listar livros |
| 5 | 12/11/2026 | CRUD completo: detalhar, editar e excluir |
| 6 | 19/11/2026 | Busca e filtros por título, autor, ano e categoria |
| 7 | 26/11/2026 | Upload e download de arquivos PDF |
| 8 | 03/12/2026 | Relatórios em tabelas, integração, testes e preparação da entrega |
| 9 | 10/12/2026 | Apresentação dos projetos finais |
| 10 | 17/12/2026 | Prova objetiva com 10 questões |

## Stack didática

- Python 3
- Flask
- SQLite, por meio do módulo `sqlite3` da biblioteca padrão do Python
- HTML5
- Jinja2, incluído com Flask
- Bootstrap 5 via CDN
- Visual Studio Code
- Git e GitHub para versionamento e entrega
